① AI 抠图

用本地 LayerStyle 抠图节点（RmBgUltra V2 / RMBG-1.4）把主体抠出来，得到透明底图。需要权重文件 model.pth 已放在 ComfyUI 的 custom_nodes\ComfyUI_LayerStyle\RMBG-1.4 文件夹里。抠完可以接 ② 生成新背景合成。

② 生成背景（Z-Image）

用 Z-Image 按文字生成一张背景图。若已抠图，会自动把主体合成到新背景上；没抠图则把生成图作为新照片打开。

③ 消除重绘（局部重绘）

先到「消除」页涂抹要重绘的区域，再回来点执行：涂抹区会交给 Flux 局部重绘按周围画面重新生成（效果比本地快速修复自然）。需要 Flux.2-Klein-4B + Qwen3-4B 编码器 + Flux2 VAE 这套文件。

④ AI 放大

用放大模型把照片放大 2 倍（细节补全型放大，不是简单拉伸）。

⑤ 美化重绘（图生图）

整张图交给 Qwen Image Edit 按下面的指令重绘：默认是提质美化，也可以改成你想要的编辑要求（英文效果更稳）。一张图约 1–2 分钟。
高级：自定义工作流（任意 ComfyUI 工作流）
在 ComfyUI 里把工作流导出为 API 格式 JSON 粘贴进来，填好注入点节点编号即可运行：当前照片会注入到图片节点，提示词注入到文本节点。
