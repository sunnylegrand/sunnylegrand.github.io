ColoRight

Photo editor · Mobile web edition + Desktop edition with local AI

ColoRight comes in two editions. The mobile edition is a web app that runs right in your phone browser. The desktop edition runs locally on your computer: on top of the full editing toolkit, it drives large AI models on your own machine through ComfyUI — cutout, background generation, inpainting, enhancement and upscaling — so your photos never leave your PC.

Mobile Edition (Web)

  • Core adjustments: exposure, contrast, saturation, color temperature, plus curves (with per-channel RGB)
  • HSL color grading, filter presets, crop & rotate, histogram
  • Smart erase: brush over distractions to remove them
  • Landscape split-pane layout; exports at the original resolution

The mobile edition is a lightweight web app and does not include the desktop edition's local large-model AI features. No install — just open it.

Open Mobile Edition View Source Code

Desktop Edition (Local)

Features: the same editor as the mobile edition (curves / HSL / crop / erase and more), plus five local AI tools —

  • AI Cutout: one-click background removal with a true alpha channel; replace with transparency, a solid color, or a new background
  • AI Background Generation: describe a scene in words and composite your subject into it
  • AI Erase & Inpaint: brush a region and let the model rebuild it from its surroundings
  • AI Enhance: one-sentence, instruction-based retouching (“brighter and cleaner”, “warmer tones”…)
  • AI Upscale: 4x super-resolution, delivered at 2x with noticeably cleaner detail

Requirements: a Windows / macOS / Linux computer; ComfyUI installed and running; an NVIDIA GPU is recommended (12 GB+ VRAM for the best experience); download the models listed below before first use.

How to use: download the code package → unzip and take the coloright-desktop folder → keep ComfyUI running → double-click start-windows.bat (macOS/Linux: start-mac-linux.sh) → the editor opens in your browser.

Desktop Edition · Local AI Models & Downloads

The desktop edition's AI features are powered by a local ComfyUI. Download the following open models and place them in the paths shown. Each model belongs to its publisher and is distributed under its own license.

0 · Foundation: ComfyUI

The runtime engine behind every AI feature. Install it first and make sure it launches.

Download ComfyUI (GitHub) →

1 · AI Cutout — BRIA RMBG-1.4

Invoked through the RmBgUltra V2 node of ComfyUI_LayerStyle; outputs a true alpha channel.

Node pack: ComfyUI_LayerStyle → download on GitHub
Place the weight file model.pth in ComfyUI/custom_nodes/ComfyUI_LayerStyle/RMBG-1.4/

Download RMBG-1.4 (Hugging Face) →

2 · AI Background Generation — Z-Image Turbo

Text-to-image background generation (the Turbo build is the desktop default; roughly 15 seconds per image).

z_image_turbo_bf16.safetensors → models/diffusion_models/
qwen_3_4b.safetensors → models/text_encoders/
ae.safetensors → models/vae/

Download Z-Image Turbo (Hugging Face · Comfy-Org) →

3 · AI Erase & Inpaint — FLUX.2 Klein 4B

Rebuilds brushed regions from their surroundings. Fast, and well suited to photo-grade cleanup.

flux-2-klein-4b.safetensors → models/diffusion_models/
qwen_3_4b.safetensors → models/text_encoders/ (the same file Z-Image uses)
flux2-vae.safetensors → models/vae/ (inside the flux2-dev repo below, under split_files/vae)

Download FLUX.2 Klein 4B (Hugging Face · Comfy-Org) →  · flux2-vae →

4 · AI Enhance — Qwen Image Edit 2511

Instruction-based editing of the whole image. The desktop edition uses the bf16 full-precision build; if VRAM is tight, grab the fp8mixed build from the same repo instead.

qwen_image_edit_2511_bf16.safetensors → models/diffusion_models/
qwen_2.5_vl_7b_fp8_scaled.safetensors → models/text_encoders/
qwen_image_vae.safetensors → models/vae/

Download Qwen Image Edit 2511 (Hugging Face · Comfy-Org repack) →  · Original repo →

5 · AI Upscale — RealESRGAN x4plus

The classic super-resolution model: renders at 4x and delivers at 2x, balancing denoise and detail recovery.

RealESRGAN_x4plus.pth → models/upscale_models/

Download RealESRGAN (GitHub Releases) →

Tip: model files are large (several GB each, up to ~40 GB) — keep enough disk space and VRAM free. After placing the files, restart ComfyUI; the connection status line at the top of ColoRight Desktop shows which AI features are available.
